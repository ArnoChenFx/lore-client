# 仓库工具参考

仓库工具使用左侧竖向导航和右侧独立滚动区。方向键、Home、End 可以移动焦点并切换
分区。顶部 **刷新** 重新读取当前仓库状态；写操作进行时，相关控件会禁用。

![Lore Client 中文仓库工具依赖页面](../../img/lore-client-repository-tools-dependencies-zh.png)

_仓库工具的“依赖”分区同时提供参数化查询、精确依赖边管理和可交互依赖图。_

## 1. 配置

### 仓库提交身份

填写 **作者名** 和 **邮箱**。仓库身份优先于客户端默认身份；两者都为空时不能创建
Revision。**保存仓库配置**只修改身份和服务器地址，并保留其他仓库配置。

| 参数/状态 | 输入与默认 | 具体作用 |
| --- | --- | --- |
| **作者名** | 最多 240 个字符；空值时输入框用客户端默认姓名作提示 | 与邮箱共同编码为仓库 `identity`，用于这个仓库之后创建的 Revision。提示文字不是已保存值。 |
| **邮箱** | 邮箱格式，最多 254 个字符；空值时提示客户端默认邮箱 | 进入 Revision 作者身份，也用于本地头像回退；不会修改已有历史作者。 |
| **活动身份** | 只读解析结果 | 明确显示当前实际会使用“仓库身份”“客户端默认身份”还是“未配置”。 |
| **保存仓库配置** | 有真实修改时才启用 | 将身份与服务器根地址一起写入仓库配置；不会发布、Push 或创建 Revision。 |

姓名和邮箱任一字段修改都会重新计算完整身份。要改用客户端默认身份，应清空两个仓库字段
并保存；不要把客户端默认值手工复制进仓库，除非确实希望仓库固定使用该身份。

### Lore 服务器地址

填写服务器根地址，例如 `lore://host:41337`，不要附加远端仓库名。保存后影响账户、
Push、Sync 和发布目标。

| 值 | 解释 |
| --- | --- |
| 空 | 当前仓库没有持久化远端；账户登录、Sync 和 Push 会禁用或引导先配置。 |
| `lore://host:41337` | 服务器根地址。后续操作结合仓库身份或发布时的仓库名定位远端。 |
| `lore://host:41337/name` | 不应保存在这里；末尾仓库名属于发布参数，不属于服务器根。 |

修改字段但未保存时，**推送当前 Branch**会禁用，防止使用“界面里新地址”和“磁盘上旧
地址”之间不明确的目标。

### 发布本地仓库

| 参数/按钮 | 输入与默认 | 具体作用 |
| --- | --- | --- |
| **远端仓库名** | 默认使用本地仓库名；服务器已有相同 Repository ID 时自动使用服务器上的正式名称；最长 1000 字符；只允许 ASCII 字母、数字、点、下划线和连字符 | 只用于在服务器上创建仓库的 URL 末段，不会重命名本地仓库。 |
| **远端说明** | 可选，最多 4096 字符 | 写入远端仓库目录，帮助浏览者理解用途；不进入 Revision 消息。 |
| **发布账户** | 可选；列出设备上已经登录的 Lore 账户，仓库已有绑定时默认选中绑定账户 | 选中账户时使用其 Token Store 凭据创建和 Push，并把它保存为仓库后续联网操作的绑定；选择“不使用账户”时，本次发布明确不携带账户，即使仓库已有绑定也不会回退使用。 |
| **发布目标** | 只读，由服务器根和远端名组合 | 在执行前确认完整目标；显示“未配置/未命名”时不能发布。 |
| **推送当前 Branch** | 需要已保存 remote URL、无待保存配置且当前能力可用 | 只向已经存在的远端推送当前 Branch，不创建远端仓库。 |
| **创建远端并推送** | 需要服务器根、远端名和发布能力 | 按“创建远端 → 保存服务器根 → Push 当前 Branch”执行。 |

发布只上传已提交内容，不包含未提交工作区修改。需要认证的服务器必须选择一个已登录
账户；允许匿名创建的服务器可以保留“不使用账户”。三个阶段可能部分成功；失败信息会
指出远端创建、配置更新或 Push 停在哪一步，不会伪造远端回滚。再次发布时，客户端会
先按稳定 Repository ID 查询服务器：同 ID 同名会跳过重复创建并继续保存配置与 Push；
同 ID 异名会显示服务器上的正式名称并阻止用新名称覆盖。

## 2. 选择性同步 View

| 参数/输出 | 输入与默认 | 具体作用 |
| --- | --- | --- |
| **View 文件路径** | 只读，通常为 `.lore/view`，旧仓库可能为 `.urc/view` | 表示规则保存在当前 Instance 的哪个文件，不是远端共享路径。 |
| **View 规则** | 多行 glob 文本，最多约 256 KiB；默认显示当前文件内容 | 按顺序决定当前 Revision 中哪些路径物化到本地。`#` 是注释，排除后可用包含规则重新加入子树。 |
| **规则诊断** | 只读，显示行号、严重级别和原因 | 在预览/应用前指出无法解析或危险的规则；有错误时预览无效。 |
| **包含文件** | 预览输出 | 应用后应在 View 范围内的 Revision 文件总数，不等于本次新增文件数。 |
| **待物化文件** | 预览输出 `+N` | 当前本机缺失、应用后会写入磁盘的文件。 |
| **待去物化文件** | 预览输出 `−N` | 当前存在、应用后会从本机撤除的历史文件；不会从 Revision 删除。 |
| **预计物化体积** | 预览输出 | 范围内文件的估算总大小；不等于需要新增下载的网络流量。 |
| **影响文件清单** | 预览输出，可能为受控截断 | 用 `materialize/dematerialize` 标明本次变化；实际应用仍处理完整集合。 |
| **预览影响** | 需要当前 Revision | 对规则和精确 Revision 做只读计算，不修改磁盘。 |
| **应用 View** | 需要草稿有修改、预览仍匹配、预览有效且工作区干净 | 保存规则，并安全撤除/重新物化完整集合。 |

规则最大约 256 KiB。应用可能撤除本机文件，因此必须先预览，且工作区必须没有本地
修改、暂存或冲突。

## 3. Layer

**添加 Layer** 参数：

| 参数 | 输入格式 | 具体作用 |
| --- | --- | --- |
| **挂载路径** | 必填的仓库相对目录，例如 `Content/Shared` | Layer 内容在父工作区中出现的位置。它是目标路径，不是来源仓库路径。 |
| **来源仓库** | 必填的 Repository ID | 指定提供 Layer 内容的独立仓库/Partition；不是服务器 URL，也不是本地文件夹。 |
| **来源路径** | 必填的来源仓库内部路径，`/` 表示根 | 决定从来源仓库挂载整棵树还是一个子树。 |
| **元数据（可选）** | 一个元数据键，例如 `release` | 让 Lore 按父 Revision 的同键值匹配来源 Revision。空值使用 Lore 默认来源解析。 |
| **暂存文件数** | 列表只读状态 | 显示该 Layer 自身尚待提交的文件，不代表父仓库暂存数。 |
| **Revision** | 列表只读状态 | 当前解析并物化的 Layer Revision。 |

**移除 Layer** 会先显示确认区。勾选 **清除 Layer 文件** 会从本机清除物化内容；
不勾选则保留未跟踪文件。Layer 是本机配置，不写入父 Revision。

| 移除参数 | 关闭时 | 开启时 |
| --- | --- | --- |
| **清除 Layer 文件** | 移除配置与受管理映射，但尽量保留未跟踪文件，适合之后手工处理。 | 同时清理 Layer 在挂载路径物化的文件；适合明确不再需要本机副本的场景。 |

若该 Layer 仍有未提交的暂存工作或本地修改，Lore 会拒绝本次移除并说明原因；先提交
或丢弃这些更改后再重试。

## 4. Link

**添加 Link** 参数：

| 参数 | 输入格式与默认 | 具体作用 |
| --- | --- | --- |
| **仓库 URL** | 必填，完整目标如 `lore://host:41337/repository` | 同时指定服务器和独立目标仓库；与配置页只保存服务器根地址不同。 |
| **挂载路径** | 必填，例如 `Tools` | Link 子树在父 Revision 文件树中的位置。必须避免覆盖父仓库已有路径。 |
| **来源路径** | 必填，`/` 表示目标仓库根 | 指定被固定引用的目标仓库子树。 |
| **pin（可选）** | Branch 名或 Revision 解析值；空值使用 Lore 默认 pin | 决定 Link 精确固定哪个目标 Revision。更新 pin 会进入父仓库下一 Revision。 |
| **禁用自动 Link 分支协同** | 默认关闭 | 开启后，父仓库创建/切换/合并 Branch 时不自动在 Link 仓库执行同名分支协同；不影响已有 pin 的固定性。 |
| **目标 Branch/Revision** | 列表只读状态 | 显示当前 pin 的解析结果，帮助判断父历史实际引用了什么。 |
| **暂存文件数** | 列表只读状态 | 表示 Link 变更等待进入下一父 Revision。 |
| **详情** | 列表动作 | 读取单条 Link 的完整状态：挂载与来源路径、跟随模式（跟随父仓库分支或固定到显式分支）、pinned Revision、pinned branch 的远端 Latest（远端未查询时明确显示不可用），以及 Link 自身的暂存状态与内部暂存文件数。 |

新建、更新 pin 和移除都会暂存到下一父仓库 Revision。列表显示目标 Branch/Revision、
暂存文件数和自动协同状态。**编辑 pin**只改变固定目标，不会自动提交。若移除会破坏
Link 内未提交的本地编辑，Lore 会拒绝本次操作并说明原因。

## 5. 依赖

### 查询依赖闭包

| 参数 | 输入与默认 | 具体作用 |
| --- | --- | --- |
| **根文件** | 每行或逗号一个仓库相对路径；默认空 | 查询起点。根文件本身进入结果；没有根文件时查询和同步禁用。 |
| **标签** | 每行或逗号分隔；默认空 | 筛选依赖边，而不是筛选文件名。空值表示不按标签限制。 |
| **深度** | `0–1024`，默认 `0` | 依赖边跳数上限；`0` 为无限。关闭传递依赖时禁用，因为只读取一跳。 |
| **包含传递依赖** | 默认开启（依赖管理页） | 开启后递归读取间接依赖；关闭时只查询一跳直接边。 |
| **显示反向依赖** | 默认关闭 | 关闭时回答“根文件依赖什么”；开启时回答“哪些文件依赖根文件”。 |
| **查询状态** | 自动使用当前暂存状态 | 以当前 Revision 为基线并叠加已暂存的依赖元数据；添加或删除依赖后会立即重新查询，因此不必先创建新 Revision。 |

**查询依赖**只读；**依赖驱动同步**会改变物化工作区并在确认后执行。

### 添加依赖

| 参数 | 输入 | 具体作用 |
| --- | --- | --- |
| **来源路径** | 必填仓库相对文件路径 | 表达“这个文件需要另一个文件”。方向会影响正向和反向查询。 |
| **目标路径** | 必填仓库相对文件路径 | 被依赖的文件。与来源相同或形成回路时会触发检查。 |
| **依赖标签** | 可选，逗号/换行分隔 | 为这一条精确边附加用途标签，供 Clone/Sync 查询过滤。 |
| **跳过依赖循环检测** | 默认关闭 | 开启后不做保护性环检测，并要求确认。不是“检测到环后允许”，而是主动绕过检测。 |

删除时使用所选边的精确“来源 + 目标 + 标签”，避免误删同路径间不同标签语义。

图谱支持缩放、适配、平移。选择边可执行 **删除精确依赖边**；选择节点可用作来源或目标。

## 6. 协作锁

锁是提示型协作信息，不是强制写保护。

| 参数/状态 | 解释 |
| --- | --- |
| **仓库相对路径** | 必填且指向单个文件，例如 `Content/Characters/Hero.uasset`。不能使用本机绝对路径；删除文件不能新建锁。 |
| **当前 Branch** | 自动使用工作区当前 Branch。锁列表也只表示该 Branch 的提示状态。 |
| **当前账户身份** | 自动取当前凭据。身份不明确时软件不会允许随意释放他人锁。 |
| **路径或所有者筛选** | 只过滤已加载列表，不修改服务端锁，也不改变 Branch。 |
| **所有者** | 只读显示名或稳定回退标识；未知所有者不等于无人持有。 |
| **锁定时间** | 只读时间戳，用于判断协作上下文，不会自动让旧锁失效。 |
| **获取协作锁** | 为精确路径登记提示型锁。它不会从存储层强制阻止其他写入。 |
| **释放** | 使用当前凭据释放自己的精确路径锁。 |

## 7. Branch 协作

### Branch 保护与 Latest

| 参数/状态 | 解释 |
| --- | --- |
| **本地 Branch** | 只列活动本地 Branch；切换下拉只改变管理目标，不检出工作区。 |
| **Branch 类别** | Lore 返回的分类信息，帮助区分工作线用途；不是用户在此编辑的标签。 |
| **Latest Revision** | 管理目标当前的精确 Latest，Reset 和保护操作都会以它重新校验。 |
| **保护状态** | 受保护时相关 Latest 写操作禁用；保护不等于文件协作锁。 |
| **刷新** | 重新读取所选 Branch 的信息和 Latest 历史，清除过期假设。 |

### Latest 指针历史与 Reset

| 参数/输出 | 解释 |
| --- | --- |
| **Reset 目标 Revision** | 只列真实 Latest 历史中当前值之前的 Revision，不能手输任意 ID。 |
| **跳过数量** | 只读影响摘要，表示会回退多少条 Latest 指针记录，不表示删除多少 Revision。 |
| **期望工作区 Revision / 期望 Latest** | 软件在执行前自动携带并重新验证，用于阻止预览后发生漂移的危险 Reset。 |
| **Reset Branch Latest** | 只移动 Branch 指针；不会删除不可变 Revision，但可能让它们不再从该 Branch 可达。 |

### Branch Diff

| 参数 | 输入与作用 |
| --- | --- |
| **来源 Branch** | 作为变化来源的活动本地 Branch。 |
| **目标 Branch** | 作为比较基准/合并目标的活动本地 Branch；必须与来源不同。 |
| **可选仓库路径** | 例如 `Content/Characters`，把只读比较限制到子树；空值比较完整仓库。 |
| **变化列表** | 显示路径、动作以及是否可自动合并。 |
| **冲突列表** | 预览来源和目标的动作组合；只是风险检查，不开启冲突会话。 |

## 8. Revision 恢复

### Revision 信息

| 参数/输出 | 解释 |
| --- | --- |
| **Revision** | 从已加载真实历史选择精确对象；下拉项显示短 ID 与标题。 |
| **Revision 编号** | Lore 在当前历史中的数字编号，适合人工检索；不是 Revision 哈希的替代。 |
| **父 Revision** | 只读拓扑父节点；合并 Revision 可能有两个。 |
| **变化文件数** | 从 Revision delta 统计的文件项，不代表完整树文件数。 |
| **Revision 元数据** | 只读键值集合，可用于审计或后续按元数据查找。 |

### 查找 Revision

| 查找参数 | 解释 |
| --- | --- |
| **Revision 编号** | 必填正整数。查找当前 Branch 历史中对应编号。 |
| **元数据键** | 必填。查找拥有该键的 Revision。 |
| **元数据值（可选）** | 留空只要求键存在；填写后要求键和值都匹配。 |
| **查找结果** | 单击后在历史中定位、设为检查对象并加载信息；不会 Checkout。 |

### 高影响操作

| 动作 | 说明 |
| --- | --- |
| 动作/参数 | 说明 |
| --- | --- |
| **Amend 消息** | 必填的新 Revision 消息。只允许当前工作区锚点等于真实 Branch Latest；Amend 创建替代 Revision，不原地改写旧对象。 |
| **已知良好 Revision** | Bisect 区间中确认没有问题的一端。默认取已加载历史较旧端，但执行前应手工核对。 |
| **已知异常 Revision** | 确认存在问题的一端，通常是当前 Revision。不得与良好端相同。 |
| **同步到 Bisect 中点** | 只执行一步并改变工作区；测试后需要继续选择新的良好/异常边界。 |
| **Restore 消息** | 必填的新 Revision 说明，应解释为什么恢复历史内容。 |
| **Restore 为新 Revision** | 把当前检出内容重放到远端最新头并新建 Revision，不把 Branch 指针硬退到历史。 |

三个动作都需要明确消息或范围，并在执行前确认影响。

## 9. 账户

账户是设备级资源，即使没有打开仓库也可以从左侧 **账户** 入口管理。左栏列出已保存
账户，右栏在 **账户 / 仓库** 两个页签间切换；Lore 的原始 JWT 始终留在 Rust
凭据存储中。

### 浏览器登录

输入任意配置了认证的 Lore 服务器根地址，再单击 **使用浏览器登录**。登录不依赖
本地仓库；系统浏览器完成认证后，账户列表会自动刷新。

### 一次性 Token 登录

| 参数 | 输入与作用 |
| --- | --- |
| **远端服务器** | 本次登录使用的临时服务器根地址，不写入任何仓库配置。 |
| **Token 类型** | 认证服务要求的类型标识。它告诉 Lore 如何解释 Access Token，不是用户显示名称。 |
| **认证服务 URL（可选）** | 只有服务器要求与仓库 remote 不同的认证入口时填写；空值使用 Lore 默认认证端点。 |
| **Access Token** | 必填的一次性敏感值。使用密码输入，不自动完成；提交后立即清空。 |

Token 使用密码输入框，提交后立即从草稿清空；不会进入偏好、提示、操作详情或账户列表。

### 身份列表

**刷新**读取已保存身份。每项参数含义：

- **显示名 / User ID**：显示名来自 Auth 服务签发的本地凭据；凭据不含名称或暂时无法解析时使用稳定 User ID。
- **Auth URL**：这份身份的认证来源，也是精确登出的作用域。
- **Resource / 授权域**：该身份被允许访问的服务或域；空值不代表全权限。
- **到期时间**：服务报告的凭据到期时间；未知时不会猜测永久有效。
- **登出**：绑定该项的 Auth URL 与 User ID，不按显示名模糊删除。
- **清除全部**：删除设备上的所有 Lore 凭据，是需要确认的全局危险动作。

### 分配到仓库

在账户详情的 **仓库** 页签中，每个已打开仓库都可以选择一个具体账户，或恢复
**自动选择**。绑定只把仓库路径、Auth URL 与 User ID 写入
`client-preferences.json`，不会写入 `.lore/config.toml`，也不会保存 Token。

固定 Lore 0.x 使用同一个身份选择 JWT，并把它记录为受保护操作的 Revision 创建者。
因此绑定账户会影响这些 Revision 的身份；解绑后仓库原有提交身份配置仍保持不变。

## 10. 元数据

这是只读浏览器。对象类型：

| 参数 | 输入与默认 | 具体作用 |
| --- | --- | --- |
| **对象类型** | Repository / Branch / Revision / File；默认 Repository | 决定后续目标字段的语义，切换后会清空不适用的旧结果。 |
| **Branch** | 活动本地 Branch；默认第一个可用项 | 读取 Branch 对象元数据，不读取远端或归档 Branch 的活动写状态。 |
| **Revision** | 精确 Revision；默认当前 Revision | 读取不可变 Revision 元数据，不读取当前工作区临时状态。 |
| **文件路径** | File 模式必填的仓库相对路径 | 指定文件对象；逐字符输入会短暂防抖后读取。 |
| **文件 Revision** | File 模式可选；默认当前 Revision | 指定在哪个历史快照读取文件元数据；空值使用当前上下文。 |
| **键 / 类型 / 值** | 只读结果列 | 保留 Lore 报告的数据类型，不把所有值强制解释成文字。 |

参数完整后会自动读取，也可单击 **读取元数据**重试。结果表显示键、类型和值，不提供
编辑按钮。

## 11. 高级诊断

### 仓库状态验证

| 参数/按钮 | 解释 |
| --- | --- |
| **仓库相对路径（可选）** | 空值验证整个仓库；填写后只检查该路径范围。改变一个字符都会使之前的 Heal 预检凭据失效。 |
| **只读验证** | 产生问题、警告和信息报告，不修改数据，并记住这次精确路径。 |
| **修复检测到的问题** | 只有当前路径等于最近只读预检路径时启用；确认框显示仓库与范围。 |

### Fragment 验证

| 参数 | 解释 |
| --- | --- |
| **Fragment 哈希** | 必填的内容寻址标识，不是文件路径或 Revision ID。 |
| **Fragment 上下文（可选）** | 用于帮助 Lore 在正确存储上下文/Partition 中解释同一地址。不了解时应留空，而不是填写文件名猜测。 |
| **验证 Fragment** | 只读检查该底层片段是否可定位和验证；不会自动 Heal。 |

### 仓库状态 Dump

| 参数 | 输入与默认 | 解释 |
| --- | --- | --- |
| **Revision** | 默认当前 Revision，可改为精确 ID | 决定 Dump 哪个不可变状态，而不是工作区未提交内容。 |
| **仓库相对路径（可选）** | 默认空 | 把树 Dump 限制到一个子树；空值从仓库根开始。 |
| **最大深度** | `1–32`，默认 `4` | 限制输出树展开层数，避免大型仓库生成过量日志；不改变仓库内容。 |
| **读取状态 Dump** | 只读 | 把结构化状态输出到诊断日志，用于支持与审计。 |

### Repository Instance

| 状态/按钮 | 解释 |
| --- | --- |
| **Instance ID** | 每个本地工作目录的稳定身份；共享 Store 的多个 Instance 彼此平等。 |
| **路径** | Lore 记录的工作目录位置；目录移动后可能过期。 |
| **Branch / Revision** | 该 Instance 最近记录的独立工作状态，不与其他 Instance 共享。 |
| **stale** | 路径已失效或记录不可达的提示；先刷新和核对磁盘再清理。 |
| **更新当前 Instance 路径** | 将当前打开目录重新登记到本 Instance，不批量修改其他项。 |
| **清理失效 Instance** | 删除 stale 元数据记录；确认框列出数量和路径，不删除仍有效的工作目录。 |

底部诊断日志汇总最近一次报告。

## 12. 维护

| 动作 | 参数与范围 | 作用 | 风险 |
| --- | --- | --- | --- |
| **开始验证** | 无参数，作用于当前仓库 | 检查本地对象、指针和工作区状态。 | 只读状态检查；若需限定路径或 Heal，转到高级诊断。 |
| **运行 GC** | 无参数，作用于当前仓库本地 Store | 回收当前仓库不再引用的本地内容。 | 可能移除之后无法离线复用的缓存；需要时会重新从远端获取。它不删除远端 Revision。 |

若需要修复，优先使用高级诊断的“先验证、后 Heal”流程，不要把 GC 当作修复仓库损坏的
通用按钮。
