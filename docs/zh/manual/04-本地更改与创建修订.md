# 本地更改与创建修订

## 扫描与视图

进入 **本地更改** 后，单击扫描/刷新按钮读取真实工作区状态。列表分为：

![Lore Client 中文本地更改、暂存分区与 Diff](../../img/lore-client-local-changes-light-zh.png)

_本地更改工作区：未暂存与已暂存内容分区显示，右侧按主要选择读取真实 Diff。_

- **未暂存**：已经修改但不会进入下一 Revision；
- **已暂存**：将进入下一 Revision 的精确内容。

右上角可以切换：

- **平铺视图**：按路径排序，适合搜索和跨目录选择；
- **树视图**：按文件夹组织，适合整目录暂存。

树视图的 **展开全部/收起全部** 只改变目录显示，不会清除文件或目录选择。文件选择和
目录选择彼此独立，选择目录不会自动高亮全部子文件。

## 桌面式多选

| 操作 | 结果 |
| --- | --- |
| 普通单击 | 只选择当前对象。 |
| Ctrl/Cmd+单击 | 增加或移除单个对象。 |
| Shift+单击 | 从主要选择到当前项做连续范围选择。 |
| Ctrl/Cmd+A | 选择当前可操作集合。 |
| 右击已选对象 | 保留聚合选区，并把右击对象作为主要上下文。 |

折叠目录不会改变后代文件选择。搜索会限制可见项，但不应被用来隐式改变暂存状态。

## 暂存与取消暂存

可以使用任一种方式：

- 双击文件或目录；
- 选中后按 Enter；
- 单击对象悬停时出现的 `+` 或 `−`；
- 右键选择 **暂存/取消暂存**；
- 单击分区标题中的 **全部暂存/全部取消**。

目录按钮会展开为明确的仓库相对路径集合。按钮只执行暂存动作，不改变目录选区和展开
状态。未暂存/已暂存之间的水平分割线可以拖动、键盘调整和双击复位。

## 右侧 Diff

选择文件后，右侧读取真实工作区内容与基准内容。标题栏在 Diff 成功加载后显示真实增删
行数，左侧列表不会用 `+0/−0` 冒充未知统计。

### 文本

可以调整上下文行数和空白处理。冲突文本若需要专业三方合并，可使用设置中配置的外部
Merge 工具；应用内当前不提供完整三方文本编辑器。

### 二进制和结构化文件

应用可按需预览：

- 常见图片与 TGA/TIFF 纹理；
- PDF 当前页；
- CSV 只读表格；
- OBJ、FBX、GLTF、GLB 三维模型；
- 其他被识别的二进制内容。

二进制预览可以全局关闭。关闭后软件停止读取预览内容，而不只是隐藏已经读取的数据。
单文件大小、格式和路径安全检查失败时会说明原因。

## 文件右键菜单

菜单会根据文件数量、状态、是否为二进制以及当前冲突会话启用或禁用动作：

- **打开**：用系统默认方式打开单个现有文件；
- **外部 Diff / 外部 Merge**：选择已配置工具；
- **保存为补丁**：仅适用于可生成文本补丁的内容；
- **在文件管理器中显示**；
- **文件时间线 / 文件历史**；
- **协作锁**：查看、获取、释放自己的锁，或打开锁管理器；
- **暂存 / 取消暂存 / 丢弃更改 / 全部暂存**；
- **忽略所选路径 / 忽略所选扩展名**；
- **复制相对路径 / 完整路径**。

Lore 当前没有文件级可恢复 Stash 时，菜单中的 Stash 会禁用并说明原因。**保存为补丁**
只是单向导出，不等同于 Stash。

## 外部 Diff 与 Merge

设置页可以保存多个工具，并指定首选工具。执行时：

- 当前存在的本地文件可直接交给工具；
- 历史版本或删除/新增的一侧使用受控临时文件；
- 参数逐项传给程序，不经过 Shell；
- 批量选择时菜单会说明只对主要文件打开，或逐个处理。

工具不可用、路径错误或模板缺少必需占位符时会报告结构化错误，不会伪造成功。

## 创建 Revision

1. 确认已暂存文件数量。
2. 输入说明，描述这次 Revision 的意图，而不是只列文件名。
3. 检查作者身份来源：仓库身份优先，否则使用客户端默认身份。
4. 单击 **创建修订**。

创建 Revision 只包含已暂存状态；未暂存文件会留在工作区。成功后 Branch Latest 前进到
新的不可变 Revision。若需要让团队看到它，还要执行 Push。

## 冲突会话

Merge、Cherry-pick 或 Revert 成功返回后，软件会比较操作前后真实状态。若新进入冲突：

1. 自动切换到本地更改；
2. 聚焦冲突文件；
3. 禁用普通暂存、取消暂存、丢弃和忽略；
4. 提供与冲突类型相符的解决动作。

未知冲突类型只读展示。未解决数变为零后，冲突会话仍然保留，直到你使用建议的可编辑
说明创建收尾 Revision。

### Restart 与 Abort

- **重新开始**：覆盖当前解决进度，回到该冲突操作的初始状态；
- **中止**：尝试恢复操作前状态。

两者都会在确认框中显示仓库、操作类型和影响。完成后软件重新读取真实快照，不会只修改
界面显示。

## 丢弃更改的风险

丢弃会修改本地文件且通常不可从 Lore Client 撤销。执行前确认：

- 选择的是仓库相对路径；
- 未跟踪文件是否另有备份；
- 不是仍需保留的冲突解决结果；
- 批量右键时主要对象和总数量正确。
