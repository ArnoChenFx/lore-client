# Lore Client 用户手册

这套手册按“先完成工作，再理解原理，最后掌握高级能力”的顺序组织。第一次使用时，
建议依次阅读快速入门、核心概念和日常工作；需要查找某个按钮或参数时，可以直接进入
克隆、仓库工具或客户端设置参考。

## 阅读路径

1. [快速入门](01-快速入门.md)：打开、初始化或克隆仓库，并认识主工作区。
2. [理解 Lore](02-理解Lore.md)：理解 Revision、Branch、Tag、Fragment、
   View、Layer、Link、Shared Store 与 Instance 背后的工作原理。
3. [工作区与导航](03-工作区与导航.md)：工具栏、侧栏、搜索、命令面板、
   多仓库标签和操作记录。
4. [本地更改与创建修订](04-本地更改与创建修订.md)：检查 Diff、选择、暂存、
   创建 Revision、使用外部工具和完成冲突收尾。
5. [历史、分支与标签](05-历史分支与标签.md)：拓扑历史、Inspector、检出、
   合并、拣选、撤销、分支和标签。
6. [大型与组合仓库](06-大型与组合仓库.md)：View、依赖图、Layer、Link、
   Shared Store 和二进制资产预览。
7. [克隆页面参考](07-克隆页面参考.md)：全部基础参数、高级参数与组合限制。
8. [仓库工具参考](08-仓库工具参考.md)：12 个仓库工具分区的按钮、参数、
   前置条件和风险。
9. [客户端设置参考](09-客户端设置参考.md)：主题、语言、身份、外部工具、
   Shared Store、布局与更新。
10. [故障处理与安全边界](10-故障处理与安全边界.md)：离线、权限、冲突、
    缺失内容、诊断和预览版本注意事项。

## 术语约定

- 中文界面使用“修订、分支、检出、拣选、撤销、标签”等术语。
- 产品对象名保留 `Lore`、`Revision`、`Branch`、`Layer`、`Link`、`View`、
  `Shared Store`、`Fragment`、`Instance`，首次出现时会解释其作用。
- 仓库名、分支名、Revision ID 和文件路径在不同语言下保持原值。
- “单击”通常只改变选择；会修改工作区或仓库的动作使用双击、菜单或明确按钮触发。

> Lore Client 当前仍是 0.x 预览版本。用于重要仓库前，请先在可恢复的副本上验证
> 克隆、同步、冲突处理、View 应用和仓库维护流程。
