# 客户端设置参考

客户端设置分为常规、默认提交身份、集成、存储和维护五个分区。设置通常立即应用并保存
到应用配置中，不需要额外“保存”按钮。

![Lore Client 中文客户端设置常规页面](../../img/lore-client-settings-general-zh.png)

_左侧选择设置分类，右侧只显示当前分类；主题和语言会立即应用。_

## 1. 常规

### 界面主题

- **跟随系统**：随操作系统浅色/深色设置变化；
- **深色**；
- **浅色**。

主题使用同一套语义设计令牌，不影响仓库内容。图像、代码或资产画布可能保持自身背景。

### 界面语言

- 简体中文（`zh-CN`）；
- English（`en-US`）。

语言立即切换。首次无偏好时，系统语言以 `zh` 开头则使用简体中文，其他可识别语言使用
英文。

## 2. 默认提交身份

参数：

- **作者名**：最多 240 个字符；
- **邮箱**：最多 254 个字符；
- **清除**：移除客户端默认身份。

该身份编码为 Lore identity，只在当前仓库没有独立身份时使用。优先级是“仓库身份 >
客户端默认身份 > 阻止创建 Revision”。默认身份不会写回仓库，也不会用于替换历史作者。

头像只根据邮箱临时请求 Gravatar；无头像、离线或邮箱无效时使用本地缩写，不保存头像
URL。

## 3. 集成

集成页分别配置 **外部 Merge 工具** 和 **外部 Diff 工具**。可添加：

- Visual Studio Code；
- Cursor；
- Beyond Compare；
- P4Merge；
- 自定义工具。

每组可保存多个工具。

### 工具列表

- 单击工具行：编辑该工具；
- **添加外部工具**：从预设或自定义模板创建；
- **设为主工具**：设为右键菜单默认项；
- **移除**：删除配置；若移除主工具，下一项成为主工具。

列表会显示程序是否在当前系统可用。

### 工具名称

用户可见名称，最长 128 个字符。为空时显示“未命名工具”并标记配置不完整。

### 可执行文件

可以填写：

- 程序绝对路径；
- 系统 `PATH` 中的命令名。

**选择**打开系统文件选择器。路径只指向程序，不应包含参数。

### 参数模板

每行是一个独立参数，不经过 Shell，因此不需要自行拼接引号或转义命令行。

Diff 必需占位符：

- `{before}`：旧版本文件；
- `{after}`：新版本文件。

可选标题：

- `{beforeLabel}`；
- `{afterLabel}`。

Merge 必需占位符：

- `{base}`：共同基线；
- `{local}`：本地版本；
- `{remote}`：远端/传入版本；
- `{merged}`：工具应写入的合并结果。

每个路径都有相应的 `*Label` 可选标题占位符。名称、程序或必需占位符缺失时，设置页会
显示“配置不完整”，调用时不会静默执行错误命令。

## 4. 存储

### 自动使用 Shared Store

开启后，Lore 按远端复用同一份 Fragment Store。它影响后续 Clone；现有仓库不会被
隐式迁移。当前固定版本不支持单次 Clone 覆盖关闭。

### 刷新

重新扫描 Store 列表、当前容量、文件数、目录是否存在和扫描错误。

### 创建 Shared Store

| 参数 | 说明 |
| --- | --- |
| **目标服务器** | 必填，例如 `lore://127.0.0.1:41337`；只用于本次创建。 |
| **设备级父目录（可选）** | Store 在本机的父目录；留空使用 Lore 默认位置。 |
| **选择** | 选择父目录。 |
| **清除** | 恢复 Lore 默认位置。 |
| **创建 Shared Store** | 创建并重新读取状态。目标服务器为空时禁用。 |

这里的服务器地址不会修改仓库配置，也不会改变服务器浏览页的临时地址。

### 容量与健康状态

摘要显示 Store 数量与当前唯一 Fragment 占用。当前版本无法重建“未去重时会占多少”
的可靠基线，因此不显示虚假的节省估算。每个 Store 显示：

- 远端地址；
- 本地路径；
- 当前容量与文件数；
- 目录缺失或扫描错误。

## 5. 维护

### 工作区分区

**恢复默认值**重置左侧栏和 Inspector 的默认宽度。它不清除仓库、主题、语言、View、
文件选择或历史。

### 应用更新

显示当前版本与更新状态：

- 检查中；
- 已是最新；
- 有可用版本；
- 检查失败；
- 安装失败；
- 当前运行方式不支持应用内更新。

**检查更新**只在桌面发布版且没有更新任务运行时可用。发现新版本后，**下载、安装并
重启**会结束当前应用进程；执行前先完成或保存工作区操作。

## 设置与仓库配置的边界

| 设置 | 作用域 |
| --- | --- |
| 主题、语言、布局、外部工具 | 当前设备上的客户端 |
| 默认提交身份 | 当前设备；只在仓库身份缺失时使用 |
| Shared Store 自动策略 | 当前设备 |
| 仓库身份、remote URL | 当前仓库，由仓库工具配置 |
| 服务器浏览地址 | 当前弹层临时值 |
| Clone 目标与高级参数 | 单次 Clone |
