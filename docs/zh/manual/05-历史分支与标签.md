# 历史、分支与标签

## 浏览 Revision 历史

**平铺模式**默认聚焦当前 Branch 的 Revision。**拓扑模式**显示真实父子关系和合并工作线。
每行可能包含：

- Revision 短 ID、标题、作者与时间；
- 精确指向该 Revision 的本地/远端 Branch 徽标；
- 附着到该 Revision 的 Tag；
- 当前工作区 HEAD 与普通选择状态；
- 尚未在当前本地工作区展示的前方 Revision。

Branch 徽标只表示当前指针，不表示 Revision “曾属于”该 Branch。Tag 徽标右键打开
Tag 菜单，不会误触发 Revision 菜单。

客户端会将当前加载历史中的作者 identity 成批交给 Auth 服务解析。真实 userId 返回
username 后，该 Revision 显示 username。远端查询暂时不可用时，只有当前仓库绑定的
userId 可以使用不含 Token 的本地账户资料作为显示缓存；其他作者保持原值。连接恢复后，
只读刷新会重新解析历史。普通 identity、未知 userId、未授权或仍无法解析的查询保留
Revision 原始 identity，当前查看者的用户名不会覆盖其他历史作者。

## 筛选与显示

筛选选项包括：

- 仅合并 Revision；
- 起始 Revision；
- 指定 Branch；
- 截止日期；
- 最大读取数量；
- 只沿所选 Branch 血缘。

显示选项包括作者列、时间列、拓扑模式和平铺模式。普通搜索只过滤已加载结果；需要更深
历史时提高读取数量或调整起始 Revision。

## Revision Inspector

### 概览

显示完整身份、时间、父 Revision 和内容来源。作者统一按以下规则展示：

- `Name <email>` 显示 Name 与独立 email，email 用于 Gravatar；
- 纯 email 将全部内容显示为 author，不重复渲染相同邮箱，但仍使用它请求 Gravatar；
- 无 email 的 username 或 identity 将全部内容显示为 author，并使用本地缩写头像。

离线、无头像或加密能力不可用时保留作者文字与本地缩写。

### 变更

变更来自所选 Revision 与父 Revision 的真实 Diff。合并 Revision 可以切换父级基线；
若第一父级没有变化，软件可以选择首个非空父级，但用户仍可显式切换。

文件列表支持平铺/目录树、搜索、多选和外部 Diff。完整补丁仅对主要选择按需读取。

### 文件树

显示该 Revision 的完整不可变文件集合。**在文件树中显示**会保留精确选择，即使树正在
重新加载。右键可打开变更、外部 Diff、在资源管理器中显示、查看文件历史、恢复到目标
状态或复制路径。

## Revision 右键菜单

| 动作 | 结果 |
| --- | --- |
| **在 Inspector 中打开** | 只读检查，不改变工作区。 |
| **检出** | 把当前工作区同步到该 Revision。 |
| **新建 Branch** | 从所选 Revision 和其来源 Branch 创建新指针。 |
| **新建 Tag** | 把 Tag 精确附着到所选 Revision。 |
| **拣选到当前 Branch** | 把该 Revision 的变化重放为当前 Branch 的新 Revision。 |
| **撤销** | 创建一个抵消所选 Revision 的新 Revision。 |
| **复制 ID / 信息** | 只复制文本。 |

检出、拣选和撤销会先确认目标和影响。右击本身只选择上下文，不执行写操作。

## Branch 总览

总览把三件事分开显示：

- 选中的 Branch；
- 当前工作区附着的 Branch；
- Branch 的 Latest Revision。

双击 Branch 才切换工作区。`ahead` 表示本地指针相对远端存在尚未推送的 Revision；
`synced` 表示已对齐，但仍应以最新刷新结果为准。

## Branch 菜单

### 本地 Branch

- **切换到此 Branch**；
- 从其 Latest **新建 Branch** 或 **新建 Tag**；
- **推送 Branch**；
- **合并到当前 Branch**；
- **归档 Branch**；
- 复制 Branch 名称。

不能把当前 Branch 合并到自己，也不能归档当前工作区附着的 Branch。

### 远端 Branch

切换时会创建或附着合适的本地工作 Branch。远端指针与本地指针类别不同，不要把远端
Branch 当作可直接编辑的工作区。

### 已归档 Branch

只提供定位 Revision、基于精确 Revision 创建 Tag 和复制元数据。归档不删除历史；
当前版本没有取消归档能力时，恢复入口会禁用。

## 新建 Branch

对话框会明确显示：

- 来源 Branch；
- 来源 Revision；
- 新 Branch 名称。

从历史 Revision 创建时，软件使用该 Revision 的真实来源 Branch；从某 Branch 创建时，
使用其精确 Latest。创建成功后工作区会附着到新 Branch。

## Tag 列表与菜单

Tag 列表按名称、目标、说明和更新时间显示，可筛选 Branch 或 Revision。新建/编辑对话框
包含：

- 目标 Branch；
- 精确目标 Revision；
- Tag 名称；
- 说明；
- 写入仓库共享元数据的提示。

菜单提供详情、定位 Revision、编辑、删除、复制名称、复制 Revision ID 和复制完整信息。
删除只移除 Tag 元数据，不删除 Revision。

## 合并、拣选与撤销

- **Merge**：把另一 Branch 的内容并入当前 Branch，可能产生双父 Revision；
- **Cherry-pick**：把某个 Revision 的变化重放到当前 Branch；
- **Revert**：创建抵消某个 Revision 的新 Revision。

三者都可能产生冲突。Lore 不原地改写目标 Revision；成功结果是新的 Revision。

## Branch 协作高级操作

仓库工具提供 Branch 保护、Latest 指针历史、Reset 和只读 Branch Diff。Reset 前会重新
确认：

- 工作区干净；
- 当前 Revision 与 Latest 未漂移；
- Branch 未保护；
- 目标仍属于真实 Latest 历史。

这类操作详见[仓库工具参考](08-仓库工具参考.md#7-branch-协作)。
