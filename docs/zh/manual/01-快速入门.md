# 快速入门

## 先理解三件事

1. Lore Client 已包含 Lore，无需另外安装命令行工具。
2. 浏览远端、克隆、发布、同步和推送需要能访问 Lore 服务；查看已缓存历史、
   暂存和创建本地修订可以离线完成。
3. Lore 的远端保存规范状态，本地目录是一个独立 `Instance`。克隆不一定下载全部
   历史内容，未用到的二进制数据可以在需要时再获取。

## 第一次启动

欢迎页有两个入口：

| 按钮 | 用途 |
| --- | --- |
| **选择项目目录** | 打开已有 Lore 仓库；若选择普通目录，软件会明确询问是否初始化。 |
| **浏览远端仓库** | 输入 Lore 服务器地址，只读浏览公开仓库，再选择一个仓库克隆。 |

选择目录后，软件会向上查找 `.lore` 或旧格式元数据，因此选择仓库中的子目录也可以
定位仓库根目录。若目录已有 Lore 元数据但已经损坏，软件会报告错误，不会把它当成
普通目录重新初始化。

### 初始化普通目录

初始化会在原目录中建立 Lore 仓库，并保留已有文件。确认前请检查：

- 该目录不是另一个 Lore 仓库的子目录；
- 现有文件确实应进入这个仓库；
- 创建首个 Revision 前已经配置作者身份。

初始化不是克隆：它创建新的仓库身份和本地历史，不会自动连接远端。

## 浏览服务器并克隆

1. 打开 **浏览远端仓库**。
2. 在 **浏览服务器地址** 中输入 `lore://主机:端口`，按 Enter 或单击 **刷新**。
3. 如果服务器需要认证，客户端会打开系统浏览器；完成认证后自动重新读取目录。已有多个账户时，也可以先在 **认证账户** 中明确选择。
4. 从仓库列表查看名称和仓库 ID，单击 **克隆**。
5. 输入 **本地目录名**，选择 **目标父目录**。
6. 初次使用保持高级选项折叠，单击 **开始克隆**。

克隆只允许在选定父目录下创建一个新的单级目录名，不会覆盖非空目录。需要指定
Revision、分支、View、Bare、Layer、Shared Store 或依赖闭包时，参见
[克隆页面参考](07-克隆页面参考.md)。

## 主工作区的四个区域

打开仓库后，界面由以下部分组成：

![Lore Client 中文深色主题修订历史工作区](../../img/lore-client-revision-history-dark-zh.png)

_修订历史工作区：左侧导航、中间 Revision 图谱与右侧 Inspector 同时保留当前上下文。_

- **顶部工具栏**：仓库切换、同步、推送、新修订、命令、搜索、服务器和设置。
- **左侧栏**：本地更改、修订历史、分支总览、标签列表、分支树和仓库入口。
- **中间主区域**：当前选择的工作视图。
- **右侧 Inspector**：当前 Revision 的概览、变更和完整文件树。

左侧栏、主区域、Inspector，以及本地更改中的上下分区都可以拖动调整。分割线支持
键盘方向键调整和双击恢复默认值，尺寸会被保存。

## 完成第一次本地 Revision

1. 进入 **本地更改**，单击 **扫描并刷新本地更改**。
2. 选择要提交的文件；普通单击单选，Ctrl/Cmd 增减，Shift 连续选择。
3. 双击未暂存文件、按 Enter，或单击行尾 `+` 将它暂存；也可以单击 **全部暂存**。
4. 在右侧 Diff 确认内容。二进制文件会使用应用内预览或显示无法预览的原因。
5. 在 **创建修订** 区输入说明。
6. 确认显示的作者身份，再单击 **创建修订**。

作者身份按以下顺序解析：

1. 当前仓库的身份；
2. 客户端设置中的默认身份；
3. 两者都没有时阻止创建 Revision。

## 与团队同步

- **同步**：读取远端分支进展，并把它并入当前本地工作线。出现冲突时会进入引导式
  冲突会话。
- **推送**：上传远端缺少的数据，然后条件性推进远端 Branch 的 Latest 指针。
  若别人已经推进该指针，推送会失败，你需要先同步并合并。
- **新修订**：把焦点带到本地更改和提交区域；它不会跳过暂存步骤。

第一次操作前，建议先打开 **仓库工具 → 配置**，检查仓库作者身份和 Lore
服务器根地址。服务器地址、远端仓库名和分支是不同概念：仓库配置只保存服务器根地址，
发布时才另外填写远端仓库名。

## 推荐的学习顺序

完成一次本地 Revision 后，继续阅读：

1. [理解 Lore](02-理解Lore.md)，建立正确心智模型；
2. [本地更改与创建修订](04-本地更改与创建修订.md)，掌握文件选择与冲突；
3. [历史、分支与标签](05-历史分支与标签.md)，开始协作。
