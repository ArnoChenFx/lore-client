# 工作区与导航

## 顶部工具栏

| 控件             | 作用                                               | 注意事项                                                   |
| ---------------- | -------------------------------------------------- | ---------------------------------------------------------- |
| 仓库切换器       | 在已打开仓库之间切换。                             | 普通切换不会显示成功提示，也不会关闭其他仓库。             |
| 远端状态         | 区分在线、离线、纯本地和需要重新认证。             | 离线远端会自动执行只读退避探测；未缓存内容仍可能无法读取。 |
| **打开项目目录** | 选择另一个本地仓库或普通目录。                     | 普通目录初始化前会再次确认。                               |
| **同步**         | 合并远端 Branch 进展。                             | 有本地写操作或冲突时可能被阻止。                           |
| **推送**         | 推进当前 Branch 的远端 Latest。                    | 必须已配置服务器且远端没有抢先推进。                       |
| **新修订**       | 进入创建 Revision 的工作流。                       | 仍需选择、暂存文件并填写说明。                             |
| **命令**         | 打开命令面板。                                     | 可键盘搜索并运行主要能力。                                 |
| **全局搜索**     | 搜索当前已加载仓库的 Revision、Branch 和文件路径。 | 不是远端全文索引。                                         |
| **服务器设置**   | 浏览远端仓库目录。                                 | 浏览地址是临时值，不修改仓库配置。                         |
| **客户端设置**   | 打开主题、语言、身份、外部工具、存储和维护。       | 设置立即应用并保存。                                       |

## 多仓库标签

每个已打开仓库拥有一个顶部标签。单击切换；关闭标签不会删除仓库目录。当前标签的
布局、Inspector 页签、文件视图和选择状态会按项目会话恢复。

右击项目标签，或聚焦标签后按 `Shift+F10`，可以打开快捷菜单。菜单支持关闭当前标签、
关闭其他标签、关闭全部标签、改名、恢复仓库默认名称，以及从包含 25 个独立类别色的 5×5 矩阵中选择标签颜色。
自定义名称与颜色只属于客户端显示偏好，不会重命名目录、Lore 仓库或远端仓库。

仓库切换与 Branch 检出不同：

- 切换仓库标签只改变当前显示的仓库；
- 检出 Branch 会在当前仓库 Instance 中同步工作区内容；
- 切换标签不会自动同步或推送。

## 左侧栏

### 主工作区入口

![Lore Client 中文深色主题分支总览工作区](../../img/lore-client-branch-overview-dark-zh.png)

_分支总览会并列呈现当前附着状态、本地与远端 Branch，以及右侧 Revision 文件树。_

- **本地更改**：扫描、查看、暂存、解决冲突并创建 Revision。
- **修订历史**：按时间或拓扑浏览 Revision。
- **分支总览**：比较本地、远端和当前工作区附着状态。
- **标签列表**：查看、筛选、创建和定位 Tag。

本地 Branch、远端 Branch 与 Tag 都使用固定英文逐层排序：同层目录优先，目录和真实对象
分别按字母排序，再递归进入下一层。分支总览固定左栏显示本地 Branch、右栏显示远端
Branch；Tag 列表筛选后仍保持同一顺序。

### Branch 树

Branch 分为本地、远端和已归档三组。单击只改变选择，双击才检出。右键菜单按对象类型
提供不同动作：

本地 Branch、远端 Branch 和标签按固定英文字符顺序排列，不会因界面语言或系统区域设置
变化。活动 Branch 与标签名称中的 `/` 会按路径段显示为可展开目录；每一层均先显示目录，
再按英文名称显示真实对象。目录折叠只改变可见行，不会改变当前选择、检出位置、标签定位
上下文或真实名称。

- 本地 Branch：切换、新建 Branch、创建 Tag、推送、合并、归档、复制名称；
- 远端 Branch：切换并创建/附着本地工作 Branch、创建 Branch 或 Tag；
- 已归档 Branch：定位精确 Revision、创建 Tag、复制 Branch 和 Revision 信息。

已归档 Branch 不提供普通检出、合并和再次归档。当前固定 Lore 版本若不支持取消归档，
恢复入口会明确禁用。已归档 Branch 保持独立扁平列表，但同样按固定英文名称排序。

### 仓库入口

- **克隆/选择性同步**：打开远端浏览和 Clone 流程。
- **仓库配置**：直接打开仓库工具的配置分区。
- **账户**：打开当前仓库远端身份管理。
- **仓库工具**：进入完整的 12 分区工具页。

底部的 **Instance** 和 **Partition** 是状态信息。Instance 标识当前本地工作目录；
Partition 是仓库内容和权限边界。把鼠标停在其上可以查看说明。

## Revision 历史工具

历史标题区提供：

- 文本筛选：按标题、作者、ID 等当前加载内容筛选；
- **筛选选项**：只看合并 Revision、指定起始 Revision、Branch、截止日期、
  最大数量，以及是否只沿所选 Branch 血缘；
- **显示选项**：显示/隐藏作者和时间列，选择拓扑图谱或平铺模式。

拓扑模式使用 `parentIds` 连接真实父节点；平铺模式聚焦当前 Branch。过滤不会改写历史，
也不会把 Branch 名称猜成拓扑关系。

## Inspector

右侧 Inspector 有三个页签：

- **概览**：Revision ID、作者、时间、父节点和摘要；
- **变更**：该 Revision 相对所选父节点的真实 Diff；
- **文件树**：该 Revision 的完整不可变文件树。

多父 Revision 可以切换差异基线。右上角 **复制完整 Revision ID** 用于复制精确标识。
文件树支持展开全部、收起全部、多选以及 **在工作区中定位**。定位只改变当前视图和选择，
不会检出 Revision。

## 搜索与命令面板

### 全局搜索

输入标题、作者、Revision ID、Branch 或文件路径。结果按 Revision、Branch、工作区文件
分组。选中结果后，软件会定位相应对象；不会自动执行仓库写操作。

### 命令面板

按 `Ctrl/Cmd+K` 打开，也可以单击工具栏 **命令**。可运行：

- 同步、推送、打开项目目录、创建新 Revision、切换 Branch；
- 编辑 View、管理 Layer、锁、依赖、Branch 协作、Revision 恢复和账户；
- 浏览远端、验证仓库、搜索、操作记录和客户端设置。

使用上下方向键选择，Enter 运行，Escape 关闭。

## 操作记录与提示

**操作记录**展示本次会话的长操作及状态：

- `queued`：已排队；
- `running`：正在执行；
- `streaming`：持续接收进度；
- `succeeded`：完成；
- `failed`：失败。

高频成功操作可能保持静默，例如刷新、暂存、取消暂存和普通 Branch 切换；错误、冲突和
长操作仍会保留明确反馈。单击 **清除已完成记录** 只清理历史显示，不撤销操作。

## 键盘与选择规则

- `Ctrl/Cmd+K`：命令面板。
- `Shift+F10`：打开当前聚焦项目标签的快捷菜单。
- `Escape`：关闭当前弹层、菜单或浮层。
- 方向键、Home、End：在支持的竖向 Tab、菜单和列表中导航。
- `Ctrl/Cmd+A`：在当前文件列表或文件树中全选。
- Enter：暂存/取消暂存当前文件，或激活当前菜单项。
- Delete：在本地更改中请求丢弃已选文件；冲突会话中禁用。
- 分割线方向键：逐步调整尺寸；双击分割线恢复默认值。
