# 大型与组合仓库

Lore Client 的特色不只是“能显示大文件”。它让用户控制哪些内容写进当前工作区、哪些
内容按依赖取得、哪些仓库组合进入历史，以及哪些叠加只属于本机。

## 用 View 缩小工作区

View 适合“仓库很大，但当前任务只需要一部分目录”的场景。

1. 打开 **仓库工具 → 选择性同步 View**。
2. 输入规则。规则按顺序匹配；排除规则缩小范围，后续包含规则可重新加入子树。
3. 单击 **预览影响**。
4. 检查包含文件数、将物化/去物化的数量、估算体积和路径清单。
5. 只有预览仍对应当前规则且校验通过时，单击 **应用 View**。

示例：

```text
# 先排除全部
**
# 再包含当前地图目录
!Content/Maps/
```

View 应用会从本机移除不再匹配的历史文件，但不会从 Revision 删除它们。工作区有本地
更改、暂存或冲突时，应用会被阻止。

## 用文件依赖描述任务闭包

依赖边表达“源文件运行或构建时需要目标文件”。例如地图依赖角色资产，角色资产依赖
纹理。标签可以区分 `runtime`、`high-resolution` 等用途。

### 查询

- 输入一个或多个根文件；
- 可选标签；
- 选择是否包含传递依赖；
- 深度 `0` 表示无限；
- 开启反向依赖可回答“谁依赖这个文件”。

结果图支持左键拖动画布、滚轮围绕指针缩放、放大、缩小和适配视图。选择节点可把路径
填入依赖编辑器；选择边可查看精确来源、目标、标签并删除该边。

### 依赖驱动同步

**依赖驱动同步**只物化根文件及参数匹配的依赖闭包。确认框会显示根文件、标签、递归和
深度。它不会自动猜测未登记的依赖，因此关键资产应先维护依赖边。

## Layer：只属于本机的覆盖层

Layer 的参数：

- **挂载路径**：内容在父工作区出现的位置；
- **来源仓库**：提供内容的仓库 ID；
- **来源路径**：来源仓库中的子树；
- **元数据（可选）**：用于按元数据匹配来源 Revision。

创建或移除 Layer 会改变当前 Instance 的组合状态。移除时：

- 不勾选 **清除 Layer 文件**：保留当前未跟踪内容；
- 勾选后：同时从磁盘清除 Layer 物化内容，属于危险动作。

Layer 不进入父仓库历史。若团队或 CI 必须得到相同组合，应使用 Link 或确保每台机器
明确配置一致的 Layer。

## Link：进入父 Revision 的固定依赖

创建 Link 时填写：

- 目标仓库 URL；
- 挂载路径；
- 来源路径；
- 可选 pin；
- 是否禁用自动 Link 分支协同。

Link 的增加、pin 更新和移除会先进入暂存状态，并随下一父仓库 Revision 保存。pin 为空
使用 Lore 默认解析；设置 pin 后父历史固定引用精确目标。**禁用自动 Link 分支协同**
只影响 Branch 操作，不会让已有 pin 自动移动。

## Shared Store：跨 Instance 复用底层内容

在 **客户端设置 → 存储** 创建 Shared Store，并可启用自动使用。之后 Clone 会按远端
查找匹配 Store。自动使用开启时，单次 Clone 中不能覆盖关闭。

Shared Store 适合：

- 同一大型仓库的多个工作目录；
- 多个仓库复用相同 Fragment；
- CI 任务避免重复下载和保存内容。

它不会共享 View、当前 Branch、暂存和本地修改。目录缺失时配置仍可能存在，设置页会
显示警告。

## 大型二进制 Diff

Diff 始终按主要选择按需读取，避免为文件列表批量传输资产。

| 类型 | 预览方式 |
| --- | --- |
| 图片、TGA、TIFF、DDS、EXR | 应用内图像预览；非浏览器格式在 Rust 安全边界转换，EXR 进行 HDR 色调映射。 |
| SVG | 在 Rust 边界栅格化为受限 PNG；脚本、链接与外部/data 图片资源不会进入 WebView。 |
| KTX2 | 使用随应用打包的 Basis 转码器绘制到 WebGL Canvas，不访问 CDN。 |
| PDF | 应用内解析并只绘制当前页。 |
| CSV | 启用二进制 Diff 时显示限制行列数量的只读表格，关闭时显示源文件文本 Diff。 |
| OBJ、FBX、GLTF、GLB | 应用内 Canvas 三维预览，不加载外部 URL 资源。 |
| WAV、OGG、MP3、FLAC | 不自动播放的应用内音频控件；实际编码仍需系统媒体管线支持。 |
| TTF、OTF | 生命周期受限的内存字体样张，关闭预览后立即卸载。 |
| ZIP、Quake PAK | 只读目录和大小信息，不解压正文。 |
| Unity AssetBundle、Godot PCK | 读取受限目录；LZMA、旧版或加密目录明确降级为容器信息。 |
| Unreal PAK | 显示可靠尾部与索引元数据；版本化索引不猜测目录项。 |
| Unreal `.uasset`、`.umap` | 显示包缩略图表中可验证的编辑器缩略图和稳定 Summary 字段，包括大型工作区包；没有缩略图时不扫描资源正文猜测图片。 |
| Blender `.blend` | 显示 `TEST` 块中的编辑器缩略图，包括大型工作区文件，以及版本、数据块和可安全统计的对象类型。 |
| Unity `.assets`、Godot `.res` | 显示稳定头部、版本、大小和可安全统计的对象类型。 |
| 其他二进制 | 显示元数据、比较信息或明确的不支持原因。 |

关闭二进制 Diff 后，文本源 SVG 与 CSV 会切换到源文件文本 Diff；其他预览格式在工作区
和 Revision 变更中停止读取正文。需要专业比较时可以在客户端设置中配置外部工具。

所有容器目录都限制返回项数，纹理解码限制维度和内存。完整源载荷默认受 20 MiB 内嵌
预览上限约束；可在 **客户端设置 → 常规 → 二进制预览** 中将单文件上限调整为任意
不小于 1 MiB 的整数，修改会立即作用于当前和后续预览。该设置不设产品最大值，较高
上限会增加内存占用和 IPC 传输量。

大型工作区 `.blend`、`.uasset` 与 `.umap` 是严格限定的例外：Lore Client 只读取有界
文件头、缩略图表和表中引用的图片，不载入或传输完整资产。固定 Lore Store 接口没有
区间读取，因此超过当前设置上限的不可变 Revision 文件保持仅元数据模式，不会为了提取
缩略图而完整下载。其他超限内容同样只显示文件元数据、变更前后大小与带符号的大小变化。
预览不会提取归档、执行脚本、跟随符号链接或读取容器外资源。

## 选择哪一种机制

| 需求 | 使用 |
| --- | --- |
| 当前机器只需要部分路径 | View |
| 只需要入口文件及显式依赖 | 依赖驱动 Clone/Sync |
| 本机叠加私有工具或资产 | Layer |
| 父历史必须固定外部组件版本 | Link |
| 多个工作目录复用底层数据 | Shared Store |
| 同一仓库并行工作但状态隔离 | 多个 Instance |
