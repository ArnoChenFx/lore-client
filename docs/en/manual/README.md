# Lore Client User Manual

This manual is arranged so you can complete useful work first, understand Lore’s model
next, and adopt advanced features when needed. New users should read Quick Start,
Understanding Lore, and Local Changes in order. Use the Clone, Repository Tools, and
Client Settings chapters as parameter references.

## Reading path

1. [Quick Start](01-quick-start.md): open, initialize, or clone a repository and learn the workspace.
2. [Understanding Lore](02-understanding-lore.md): learn how Revisions, Branches, Tags,
   Fragments, Views, Layers, Links, Shared Stores, and Instances work.
3. [Workspace and Navigation](03-workspace-and-navigation.md): toolbar, sidebar, search,
   Command Palette, repository tabs, and Operation History.
4. [Local Changes and Creating Revisions](04-local-changes-and-revisions.md): inspect Diffs,
   select and stage files, create a Revision, use external tools, and finish conflicts.
5. [History, Branches, and Tags](05-history-branches-and-tags.md): topology history,
   Inspector, checkout, merge, cherry-pick, revert, Branches, and Tags.
6. [Large and Composite Repositories](06-large-and-composite-repositories.md): Views,
   dependency graphs, Layers, Links, Shared Stores, and binary previews.
7. [Clone Page Reference](07-clone-page-reference.md): every basic and advanced Clone
   parameter and the combinations that are intentionally unavailable.
8. [Repository Tools Reference](08-repository-tools-reference.md): controls, parameters,
   prerequisites, and risks for all 12 sections.
9. [Client Settings Reference](09-client-settings-reference.md): theme, language, identity,
   external tools, Shared Store, layout, and updates.
10. [Troubleshooting and Safety Boundaries](10-troubleshooting-and-safety.md): offline use,
    permissions, conflicts, missing content, diagnostics, and preview-version caveats.

## Terminology

- The English interface uses Revision, Branch, Checkout, Cherry-pick, Revert, and Tag.
- Lore object names such as Layer, Link, View, Shared Store, Fragment, and Instance are
  kept as product terms and explained on first use.
- Repository names, Branch names, Revision IDs, and file paths are never translated.
- A normal click generally changes selection only. Actions that write to the workspace
  or repository require a double-click, menu command, or explicit button.

> Lore Client is still a 0.x preview. Before using it with an important repository,
> validate Clone, Sync, conflict handling, View application, and maintenance workflows
> on a recoverable copy.
